CSV Cleaner for Freelancers

Does one thing: takes a messy CSV and returns a clean one. No internet needed.

Use cases

1. Client sends a broken CSV

Headers like " First Name ", empty rows, weird encoding. Drag it onto CSV Cleaner → get client_cleaned.csv with first_name,last_name,email.

2. Excel export with blank lines

Excel often exports blank rows. Cleaner removes them automatically.

3. Bank CSV in latin1

Auto-detects encoding, converts to UTF-8 so it imports cleanly elsewhere.

How to use

  1. Run csv-cleaner input.csv (or drag file onto the app)
  2. Check the preview of first 5 rows
  3. Find input_cleaned.csv next to your original

Config toggles

  • Header normalization: on/off (default on)
  • Remove empty rows: on/off (default on)
  • Encoding: auto-detect (default)
